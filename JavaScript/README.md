## Tips for JavaScript Solutions

- Use modern ES6+ features (arrow functions, destructuring, etc.)
- Prefer `const` and `let` over `var`
- Include JSDoc comments for functions
- Consider both time and space complexity

## Common Patterns

- Hash Maps: `Map()` or `{}`
- Arrays: `[]`
- Sets: `Set()`
- Heaps: Use custom implementation or library
- Queues: Use arrays with `shift()`/`push()` or implement
- Stacks: Use arrays with `pop()`/`push()`
