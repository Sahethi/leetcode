# C++ Solutions

This directory contains LeetCode solutions implemented in C++.

## Solutions

1. [Two Sum](1_two_sum.cpp) - Easy

## Running Solutions

To compile and run a solution locally:

```bash
g++ -std=c++17 1_two_sum.cpp -o two_sum
./two_sum
```

## Tips for C++ Solutions

- Use modern C++11/14/17 features
- Prefer STL containers and algorithms
- Include proper headers
- Consider memory management and performance

## Common Patterns

- Hash Maps: `unordered_map<K, V>`, `map<K, V>`
- Arrays: `vector<T>`, native arrays
- Sets: `unordered_set<T>`, `set<T>`
- Heaps: `priority_queue<T>`
- Queues: `queue<T>`, `deque<T>`
- Stacks: `stack<T>`
