# Rust Solutions

This directory contains LeetCode solutions implemented in Rust.

## Solutions

1. [Two Sum](1_two_sum.rs) - Easy

## Running Solutions

To test a solution locally:

```bash
rustc 1_two_sum.rs
./1_two_sum
```

Or use Cargo for testing:

```bash
cargo test
```

## Tips for Rust Solutions

- Leverage Rust's ownership system
- Use iterators for efficient operations
- Include proper type annotations
- Handle errors explicitly

## Common Patterns

- Hash Maps: `HashMap<K, V>`
- Vectors: `Vec<T>`
- Sets: `HashSet<T>`
- Heaps: `BinaryHeap<T>`
- Collections: `use std::collections::*`
