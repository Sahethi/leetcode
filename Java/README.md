```bash
javac 1_two_sum.java
```

## Tips for Java Solutions

- Use appropriate data structures from `java.util`
- Follow Java naming conventions
- Include JavaDoc comments for methods
- Consider time/space complexity trade-offs

## Common Patterns

- Hash Maps: `HashMap<K, V>`
- Arrays: `int[]`, `Integer[]`
- Lists: `ArrayList<T>`, `LinkedList<T>`
- Sets: `HashSet<T>`, `TreeSet<T>`
- Queues: `Queue<T>`, `PriorityQueue<T>`
- Stacks: `Stack<T>` or `Deque<T>`
