# LeetCode Solutions

A collection of my LeetCode problem solutions organized by programming language.

## Repository Structure

```
.
├── Python/          # Python solutions
├── Java/            # Java solutions
├── JavaScript/      # JavaScript solutions
├── C++/             # C++ solutions
├── Go/              # Go solutions
└── Rust/            # Rust solutions
```

## Naming Convention

Solutions are named using the following format:
```
<problem-number>_<problem-name>.<extension>
```

Example: `1_two_sum.py`, `2_add_two_numbers.java`

## Solution Template

Each solution file should include:
- Problem description (as a comment)
- Problem link
- Time and space complexity analysis
- Solution code
